## 一、强烈推荐（5星）：caveman —— AI"原始人说话"，帮你省 65% token
**是啥：**一个给 AI 智能体用的"技能+代理"：强制 AI 用最精简的"原始人语言"回答，实测能砍掉 **65% 的 token 消耗**。四月底上线，九月底病毒式爆红，现在 10.9 万星（今日+507）。
**为什么5星：**你昨天刚说过"再部署一个项目就要多配一个 API 大模型，造成 token 双倍消耗"——caveman 解决的正是这个问题：同样的活，token 用量少一半以上，等于直接省钱。你有阿库、有 OpenClaw、有本地模型，给它们套上这个技能，能明显降低每月的 API 账单。
**对你的好处：**花钱买 token 的场合，省 65% = 同样的钱多用一倍的量。贴你价格敏感的风格。

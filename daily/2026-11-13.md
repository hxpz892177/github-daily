# GitHub热门Top10 · 2026-11-13

> 每天抓取GitHub热门项目，大白话解读，告诉你值不值得折腾。

## 🔥 强烈推荐（5星）

1、[ChromeDevTools/chrome-devtools-mcp](https://github.com/ChromeDevTools/chrome-devtools-mcp)：把Chrome浏览器调试能力直接接给编码agent的MCP工具。
Chrome DevTools官方出的MCP服务器，agent可以查看网页DOM、控制台报错、网络请求、性能面板，自己调试页面。TypeScript，5.52万星。你想让兔子agent自动打开网页、查报错、抓数据，这是最对口的底座之一。
- **星级**：★★★★★
- **语言**：TypeScript
- **Star**：5.52万（今日+60）
- **部署建议**：旧笔记本上 `npm i chrome-devtools-mcp@latest -g`，接到你的兔子/编码agent配置里。第一步：装好后跑命令启动MCP服务，在agent里确认能连上Chrome。

## ⭐ 值得装（4星）

2、[a2ui-project/a2ui](https://github.com/a2ui-project/a2ui)：让AI agent流式生成界面、用原生组件渲染的开源生成式UI框架。
agent只下发布局JSON，前端用React/Angular/Lit/Flutter/SwiftUI等原生组件渲染，不用截图拼界面。TypeScript，1.73万星（今日+121）。你做HUD网页和机器人面板时，这套思路能让AI直接搭出像样的界面。
- **星级**：★★★★ 🐎 黑马
- **语言**：TypeScript
- **Star**：1.73万（今日+121）
- **部署建议**：先不部署，打开官方Composer在线编辑器试生成一段UI JSON，看懂数据格式。第一步：访问 README 里的 Composer 链接，在agent提示词里贴一段试效果。

3、[rustfs/rustfs](https://github.com/rustfs/rustfs)：Rust写的S3兼容高性能对象存储。
自建一套类似阿里云OSS的存储服务，可迁移、和其它S3平台共存，Docker镜像现成。Rust，3.60万星。你飞牛NAS上可以拿来存照片、视频、模型文件，给知识库和agent当统一文件仓。
- **星级**：★★★★
- **语言**：Rust
- **Star**：3.60万（今日+46）
- **部署建议**：NAS Docker起一个对象存储容器，挂一块硬盘当存储目录。第一步：看官网installation文档，拉Docker镜像起步。

4、[aimod-cc/Agent2API](https://github.com/aimod-cc/Agent2API)：本地AI路由网关，一个地址统一调用50多家AI客户端。
复用现有客户端登录态，50+ AI客户端通过一个OpenAI兼容的base URL接入，有Windows/macOS/Linux桌面端、无头服务器和Docker版（amd64/arm64），无需Node运行时。Rust，2.2k星。你在Ollama、兔子和各种模型之间切换，用它统一收口最省事。
- **星级**：★★★★
- **语言**：Rust
- **Star**：2.2k（今日+56）
- **部署建议**：NAS Docker（arm64也支持）起网关，把你常用的模型/客户端接进来，agent统一走这个地址。第一步：看 docs/install.en.md，先Docker起服务再配provider。

## 👀 看兴趣（3星）

5、[backnotprop/plannotator](https://github.com/backnotprop/plannotator)：盯着agent干活的规划、批注、评审工作台。
在一个工作区里梳理目标、做决定、写计划、批注、评审代码，再把反馈发回给agent；安装脚本自动识别你已装的agent并配好hooks和技能。TypeScript，1.02万星。适合想规范管理agent任务流程的人。
- **星级**：★★★
- **语言**：TypeScript
- **Star**：1.02万（今日+100）
- **部署建议**：旧笔记本跑安装脚本，配合你现有的编码agent用。第一步：clone仓库跑一键安装，看它自动识别到哪些agent。

6、[alibaba/open-code-review](https://github.com/alibaba/open-code-review)：阿里规模验证过的混合架构代码评审工具。
确定性流水线 + LLM Agent结合，做到行级精准评审，安全、快、经过大流量打磨。Go，5.01万星（今日+206）。纯开发者向，你不写正式代码的话用不上，但思路值得了解。
- **星级**：★★★
- **语言**：Go
- **Star**：5.01万（今日+206）
- **部署建议**：不建议部署，了解即可。等你以后有自己的代码仓库要做自动评审再回来。

- **星级**：★★
- **语言**：Go
- **Star**：9.2k（今日+173）

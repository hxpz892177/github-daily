## 🔥 强烈推荐（5星）

1、[tashfeenahmed/freellmapi](https://github.com/tashfeenahmed/freellmapi)：一个接口聚合87个免费大模型服务商、1313个免费模型端点。

- **星级**：★★★★★
- **语言**：TypeScript
- **Star**：5.31万（今日+579）
- **部署建议**：NAS或旧笔记本用Docker起一个服务端，在agent里把模型地址指到本地 `/v1`。第一步：看README的Docker段起容器，先在设置里选一个免费模型连通对话。

## ⭐ 值得装（4星）

2、[huytieu/COG-second-brain](https://github.com/huytieu/COG-second-brain)：会自我进化的agent第二大脑，Obsidian + Git + Markdown。
Cognition + Obsidian + Git，AI agent把学到的东西写成 `.md` 文件并用版本管理，没有数据库、不被厂商锁定，笔记和记忆都在自己手里。Python，1.49k星（今日+37）。正好对口你关心的"AI有长期记忆、知识库自己掌握"。
- **星级**：★★★★
- **语言**：Python
- **Star**：1.49k（今日+37）
- **部署建议**：旧笔记本clone仓库，配一个本地Obsidian笔记目录当记忆库。第一步：按Quick Start装好，让agent先把几条聊天沉淀成md。

3、[PrefectHQ/fastmcp](https://github.com/PrefectHQ/fastmcp)：用Python快速搭建MCP服务器和客户端的框架。
官方还有对应的TypeScript版，主打快、Pythonic，帮你把工具封装成标准MCP能力给agent调用。Python，2.86万星（今日+82）。想给兔子加自己的MCP工具（读HA、控旧硬件）时，用它写服务端最省事。
- **星级**：★★★★
- **语言**：Python
- **Star**：2.86万（今日+82）
- **部署建议**：旧笔记本 `pip install fastmcp`，照Quick Start写第一个工具函数。第一步：装好后跑通示例MCP服务，让兔子能列出这个工具。

4、[google-labs-code/stitch-skills](https://github.com/google-labs-code/stitch-skills)：遵循Agent Skills开放标准的agent技能库。
为Google Stitch MCP服务设计，同时兼容Codex、Gemini CLI、Claude Code、Cursor、OpenCode等编码agent，技能按开放标准写，可手动安装。TypeScript，9.55k星（今日+247）。想扩充兔子/编码agent的现成技能时，可从这类标准技能里挑着装。
- **星级**：★★★★
- **语言**：TypeScript
- **Star**：9.55k（今日+247）
- **部署建议**：不单独部署，作为技能包挂到你在用的agent里。第一步：clone后读技能清单，挑一个和自己需求相近的技能看它的写法。

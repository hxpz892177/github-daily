# GitHub热门Top10 · 2026-11-10

> 每天抓取GitHub热门项目，大白话解读，告诉你值不值得折腾。

## 🔥 强烈推荐（5星）

1、[homeassistant-ai/ha-mcp](https://github.com/homeassistant-ai/ha-mcp)：让Claude/ChatGPT直接控制你的Home Assistant智能家居。
这是一个MCP服务器，把你家里的灯泡、空调、传感器全部暴露给AI助手，你用嘴说"把客厅灯调暗一点"或者"今天出门窗户关了没"，AI直接帮你查帮你开。
- **星级**：★★★★★
- **语言**：Python
- **Star**：6.3k（今日+31）
- **部署建议**：你已有Home Assistant，直接在飞牛NAS的Docker里跑一个容器，配上你的HA长期访问令牌，Claude/兔子agent就能语音控家了。第一步：clone仓库看README的Docker Compose那段。

2、[vercel-labs/agent-browser](https://github.com/vercel-labs/agent-browser)：Vercel官方出的给AI agent用的浏览器自动化CLI。
Rust写的，4.8万星。AI agent不用打开图形界面浏览器，直接在命令行里打开网页、点按钮、填表单、抓数据。你想让兔子ExTV自动刷抖音/查快递/填表单，这个就是底座。
- **星级**：★★★★★ 🐎 黑马
- **语言**：Rust
- **Star**：48.8k（今日+916）
- **部署建议**：旧笔记本或飞牛NAS上Docker直接跑，二进制单文件。第一步：下载release二进制，`agent-browser open https://baidu.com` 试试。

## ⭐ 值得装（4星）

3、[ranxianglei/billion-context](https://github.com/ranxianglei/billion-context)：让AI一次聊几个月不健忘的上下文压缩插件。
100K上下文窗口就能扛住十亿级token的超长会话，自动压缩旧记忆。你那个"AI要有长期记忆"的需求，这个就是方案——把和AI的几个月聊天自动提炼成关键信息，不用每次重新介绍自己。
- **星级**：★★★★
- **语言**：TypeScript
- **Star**：5.9k（今日+760）
- **部署建议**：接在你现有的Ollama/兔子agent前面当中间层，npm装好配一下接口地址就行。第一步：clone下来看examples目录。

4、[yjid/kensaku](https://github.com/yjid/kensaku)：本地秒搜所有文件、代码甚至截图里的文字。
Rust写的文件启动器，带OCR——你存到NAS里的老照片、PDF、截图，记得大概内容就能搜出来，不依赖云服务，隐私全在本地。
- **星级**：★★★★
- **语言**：Rust
- **Star**：1.5k
- **部署建议**：飞牛NAS上Docker跑一个，索引你的NAS文件夹，旧笔记本上装客户端搜。第一步：release里下载对应架构二进制，`kensaku index /你的/NAS路径`。

5、[emanuele-em/kanzo](https://github.com/emanuele-em/kanzo)：给人和AI agent一起用的极简看板。
单二进制才4.7MB，内存吃5MB，agent每次回复只花10-60个token。自托管在NAS上，你拖卡片，AI agent也能往里加任务、勾任务，适合个人Todo+agent协作。
- **星级**：★★★★
- **语言**：Rust
- **Star**：1.1k
- **部署建议**：飞牛NAS Docker一行命令起，浏览器打开就用。第一步：`docker run -d -p 3000:3000 kanzo`。

## 👀 看兴趣（3星）

6、[meta/astryx](https://github.com/meta/astryx)：Meta新开源的全套可定制设计系统，专门给AI agent用的。
2.1万星、今天+3278，Meta刚放出来的大杀器。组件库+设计规范全开源，而且从一开始就按"AI能直接生成UI"来设计的。纯前端React/TS项目。
- **星级**：★★★
- **语言**：TypeScript
- **Star**：21.2k（今日+3,278）
- **部署建议**：不建议部署，了解即可。你不做前端开发，但做HUD/兔子界面时可以抄它的组件样式。

7、[anthropics/claude-quickstarts](https://github.com/anthropics/claude-quickstarts)：Anthropic官方Claude API入门项目合集。
官方出的各种示例：聊天机器人、RAG、agent、MCP服务器怎么写。你想用硅基流动/DeepSeek的兼容API套Claude的玩法，这里抄代码最快。
- **星级**：★★★
- **语言**：Python
- **Star**：2.0k（今日+551）
- **部署建议**：不部署，当教程看。clone下来挑一个跟你语音助手相关的example，把API地址改成DeepSeek就能跑。

8、[sherlock-project/sherlock](https://github.com/sherlock-project/sherlock)：输入一个用户名，找出他在全网哪些网站注册过。
10.8万星的老牌工具，Python写的。查你自己的用户名有没有被别人盗用注册、查小号用。一条命令扫400多个网站。
- **星级**：★★★
- **语言**：Python
- **Star**：108.1k（今日+4,267）
- **部署建议**：旧笔记本上`pip install sherlock-project`，跑一次查完就删。第一步：`sherlock 你的用户名`。

## 📌 关注（2星）

9、[we-promise/sure](https://github.com/we-promise/sure)：人人参与写的开源个人记账理财App。
Ruby写的，你不是有房贷装修贷信用卡分期要盯吗？这种自托管记账工具能跑在NAS上，数据自己掌握。但Ruby栈对你来说稍重。
- **星级**：★★
- **语言**：Ruby
- **Star**：11.3k（今日+184）
- **部署建议**：想折腾就Docker起一个，配合你那个可视化负债表工具用。不折腾就先用现有Excel。

- **Star**：17.1k（今日+574）
- **部署建议**：不建议部署，了解即可。等你以后真做人形机器人 inverse 动力学再回来翻。

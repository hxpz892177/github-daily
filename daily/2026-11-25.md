# GitHub热门Top10 · 2026-11-25

> 每天抓取GitHub热门项目，大白话解读，告诉你值不值得折腾。

## 🔥 强烈推荐（5星）

今日主榜与候补重复度高，候选以课程教程、通用基础组件为主，没有同时满足「很热门 + 有运行环境 + 贴近话题」的5星项目，本期暂不设5星。

## ⭐ 值得装（4星）

1、[earendil-works/pi](https://github.com/earendil-works/pi)：可自己定制的轻量 agent 外壳（harness）。🐎 黑马
自带命令行交互、脚本/JSON 自动化、RPC 控制和 TypeScript SDK，能用扩展、技能、提示词模板、主题把它改成自己的工作流；不内置子 agent 和计划模式，留空给你自己补。TypeScript，shields 显示约12.4万星（今日+204，以仓库页面为准）。和你在兔子本地智能体上折腾的 agent 方向直接对口，可参考它的技能/扩展打包方式。
- **星级**：★★★★
- **语言**：TypeScript
- **Star**：约12.4万（今日+204，以仓库页面为准）
- **部署建议**：旧笔记本装 Node 后用 npm 装 CLI 试用，先跑通交互模式，再接自己的大模型 API；想改造技能结构时再看 README 的扩展/技能文档。第一步：看 README 的命令行安装与用法章节。

## 👀 看兴趣（3星）

2、[pgvector/pgvector](https://github.com/pgvector/pgvector)：给 Postgres 加向量相似度检索的开源扩展。
把文本、图片的向量和业务数据存一起，做精确/近似最近邻检索，支持 L2、余弦、内积等距离，带 ACID 和事务。C，24k星（今日+14）。想在 NAS 上搭本地知识库/RAG 时，它是检索底座之一，配合 Docker 里的 Postgres 使用。
- **星级**：★★★
- **语言**：C
- **Star**：24k（今日+14）
- **部署建议**：NAS Docker 起一个 Postgres 容器后安装该扩展，先存几条测试向量试检索；不需要单独跑向量数据库。第一步：看 README 的 Linux 安装段，确认 Postgres 版本。

3、[home-assistant/apps](https://github.com/home-assistant/apps)：Home Assistant 官方应用（插件）仓库。
里面是 HA 官方维护的各种附加应用，比如 MQTT  broker、数据库、Samba 文件共享、配置编辑器、Zigbee 网关等，在 HA 前端里直接安装配置。Shell，2.3k星（今日+0）。你玩智能家居/Home Assistant 时，找官方插件先翻这个仓库最对口。
- **星级**：★★★
- **语言**：Shell
- **Star**：2.3k（今日+0）
- **部署建议**：不用单独部署；在已装好的 HA 前端「加载项/应用」里浏览安装。第一步：对照目录找你需要的 MQTT、文件共享等插件说明。

4、[nginx/nginx](https://github.com/nginx/nginx)：官方 NGINX 开源仓库。
高性能 Web 服务器和反向代理，做网站静态托管、端口转发、HTTPS 入口、域名分流都常用，是 NAS 自托管服务最常见的前置网关。C，Star 以仓库页面为准（今日+158）。你在飞牛/NAS 上把多个自托管服务挂到一个域名下时，绕不开它。
- **星级**：★★★
- **语言**：C
- **Star**：以仓库页面为准（今日+158）
- **部署建议**：NAS Docker 方式起 nginx 反代容器，先把一个已有服务的端口转发出去；配置不熟时先用官方示例改端口和代理地址。第一步：看仓库 README 的安装/配置说明。

5、[CoolDude2349/Offline-HTML-Games-Pack](https://github.com/CoolDude2349/Offline-HTML-Games-Pack)：352 个单文件离线 HTML 游戏合集。
每个游戏都是一个独立 HTML 文件，不联网也能玩，适合断网环境、旧笔记本或旧手机浏览器打开。HTML，297星（今日+2）。符合你怀旧游戏的口味，拿来当离线消遣包很合适。
- **星级**：★★★
- **语言**：HTML
- **Star**：297（今日+2）
- **部署建议**：下载 ZIP 解压到旧笔记本/旧手机，浏览器直接点开对应 HTML 即可，无需安装。第一步：Code → Download ZIP。

6、[jackfrued/Python-100-Days](https://github.com/jackfrued/Python-100-Days)：Python 100 天从新手到大师中文教程。
从基础语法到进阶、数据分析、AI 智能体开发等章节，按天排好的中文编程学习路径，配套 B 站视频。Jupyter Notebook，18.8万星（今日+29）。你自学自动化、设备维护和后续接 AI 应用时，跟着这套中文课补 Python 基础比较顺手。
- **星级**：★★★
- **语言**：Jupyter Notebook
- **Star**：18.8万（今日+29）
- **部署建议**：在线阅读即可，不用部署；旧笔记本装 Python 环境后按章节敲练习。第一步：从目录里的「Python 基础」章节开始。

- **星级**：★★

9、[xbtlin/ai-berkshire](https://github.com/xbtlin/ai-berkshire)：AI 时代的价值投资研究 Skill 合集。
把巴菲特、芒格等价值投资方法论结构化，做成兼容 Claude Code / Codex 的 agent 研究技能框架，一个人配编码 agent 当一个投研团队用，含财报课程和历史报告索引。HTML，17k星（今日+15）。你平时关注宏观、政经和投资话题，可参考它把方法论做成 agent 技能的思路；涉及投资判断仅供研究参考。

10、[AbdurazaaqMohammed/MP-Manager](https://github.com/AbdurazaaqMohammed/MP-Manager)：安卓双栏文件管理器，主打 APK 工具。

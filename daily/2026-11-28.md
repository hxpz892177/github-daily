# GitHub热门Top10 · 2026-11-28

> 每天抓取GitHub热门项目，大白话解读，告诉你值不值得折腾。

## 🔥 强烈推荐（5星）

本期无同时满足「当下很热门 + 本机有运行环境 + 贴近近期话题」的项目，5星节留空。

## ⭐ 值得装（4星）

1、[ToolJet/ToolJet](https://github.com/ToolJet/ToolJet)：开源低代码内部工具平台，AI 描述即可生成页面，还带 MCP 接口。
它不用写多少代码，拖一拖、用 AI 提示就能搭管理后台、数据看板、业务小应用；官方提供 MCP server，你的本地 agent 可以直接调它去查库、填单。跑在自己服务器上，数据不外泄。
- **星级**：★★★★
- **语言**：HTML / JavaScript
- **Star**：4.1万（今日+8）
- **部署建议**：装到飞牛 NAS 或 OECT 的 Docker 里，官方有现成 compose；先跑起来对着它的示例看板改，再把兔子 agent 通过 MCP 接进来。

## 👀 看兴趣（3星）

2、[CoplayDev/unity-mcp](https://github.com/CoplayDev/unity-mcp)：MCP 服务器，让 AI 助手直接控制 Unity 编辑器。
配上 MCP 后，AI 能在 Unity 里建场景、挂组件、调参数，适合做游戏或 3D 演示；本质是给 agent 多了一个操作 3D 引擎的手。
- **星级**：★★★
- **语言**：C#
- **Star**：1.6万（今日+29）
- **部署建议**：先在旧笔记本上装 Unity 编辑器，再按 README 接 MCP；旧设备带不动 Unity 时不建议部署，了解即可。

3、[NirDiamant/GenAI_Agents](https://github.com/NirDiamant/GenAI_Agents)：讲清楚怎么搭 AI agent 的图文教程与实现合集。
28 章、148 张配图，无代码先讲决策思路，再配从对话机器人到多智能体系统的示例代码，适合零基础先建立 agent 全貌。
- **星级**：★★★
- **语言**：Jupyter Notebook
- **Star**：2.5万（今日+8）
- **部署建议**：不用部署，直接在仓库在线看；想动手就挑里面最简单的对话机器人示例，配合本地 Ollama 跑通第一个小 agent。

4、[patchy631/ai-engineering-hub](https://github.com/patchy631/ai-engineering-hub)：AI 工程学习资源大合集，覆盖 RAG、agent、模型实战。
把入门路线、教程、工具清单整理成一个仓库，方便顺着学；对想搞懂本地 AI 整套链路的人是个目录型地图。
- **星级**：★★★
- **语言**：Jupyter Notebook
- **Star**：4.2万（今日+16）
- **部署建议**：纯学习资料，收藏备用；按里面 RAG、agent 章节挑感兴趣的跟着做，不需要额外装服务。

5、[libretro/RetroArch](https://github.com/libretro/RetroArch)：开源复古游戏模拟器前端，一套界面跑各种老游戏机。
通过加载不同核心（模拟器库），能玩 FC、GBA、街机等老游戏；跨平台，旧笔记本、旧手机都能装，正好对上怀旧游戏的爱好。
- **星级**：★★★
- **语言**：C
- **Star**：1.5万（今日+15）
- **部署建议**：旧手机或旧笔记本直接装官方客户端，再下载对应核心和游戏包即可；NAS 上可搭前端做家庭游戏库，先从手机版试起。

6、[keycloak/keycloak](https://github.com/keycloak/keycloak)：开源统一身份认证与单点登录（SSO）系统。
自己 NAS 上跑了一堆服务（知识库、看板、工具）时，用它统一管账号、登录和权限，不用每个服务各设一套密码。
- **星级**：★★★
- **语言**：Java
- **Star**：3.8万（今日+27）
- **部署建议**：Docker 起在飞牛 NAS 上，先建好一个管理员账号，再把需要登录的服务逐个接进来；初期只有一两个自用服务时可以先收藏。

## 📌 关注（2星）

7、[ESPARGOS/esp-sdr](https://github.com/ESPARGOS/esp-sdr)：把普通 ESP32 变成接收型软件无线电（SDR）的固件。
不用额外买 SDR 硬件，通过芯片未公开的调试通道读取射频采样，电脑浏览器里就能看频谱；其中部分固件由 AI 辅助生成。
- **星级**：★★
- **语言**：C
- **Star**：1.4k（今日+3）
- **部署建议**：有 ESP32 板子可按浏览器安装器刷固件、在网页查看器连接；门槛偏硬件/射频，先收藏资料，玩熟 ESP32 再上手。

8、[NYLLON-SOFTWARE/SignuDoc](https://github.com/NYLLON-SOFTWARE/SignuDoc)：开源自托管电子签名应用，PDF 上传、放签字位、发签署链接。
MIT 协议，可部署到自己的 Vercel 账号，按席位不收费；签完保留审计证书，适合小团队或个人合同场景。
- **星级**：★★
- **语言**：TypeScript
- **Star**：3.6k（今日+197）
- **部署建议**：不想用 Vercel 时也可 Docker 自建；家里日常用不太得上，先收藏，有合同签署需求再搭。

9、[egoist/mygo](https://github.com/egoist/mygo)：用 Go 写桌面应用的脚手架，可出原生 UI 或网页前端。
帮你省去搭桌面项目的重复活儿，专注写业务；面向想做本地工具软件的开发者，成品跨系统运行。
- **星级**：★★
- **语言**：Go
- **Star**：7.1k（今日+133）
- **部署建议**：开发者向，暂不建议部署；等以后想给兔子/机器人做个本地桌面小工具时，再回来参考它的脚手架。

10、[mjmirza/app-store-compliance](https://github.com/mjmirza/app-store-compliance) 🐎 黑马：iOS / 安卓上架前的合规检查手册与自检清单。
把苹果 App Store、Google Play 容易被拒的原因整理成可对照的清单，上架前先自己扫一遍；纯文档型参考仓库，今天热度暴涨。
- **星级**：★★
- **语言**：Shell
- **Star**：以仓库页面为准（今日+530）
- **部署建议**：不部署，了解即可；以后真要把自己做的 App 上架商店，先翻这份清单对照自查。

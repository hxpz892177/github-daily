# GitHub热门Top10 · 2026-11-14

> 每天抓取GitHub热门项目，大白话解读，告诉你值不值得折腾。

## 🔥 强烈推荐（5星）

1、[lidge-jun/opencodex](https://github.com/lidge-jun/opencodex)：给Codex/Claude Code换模型的通用提供商代理。
装一个代理层，就能在Codex CLI、App、SDK里用Claude、Gemini、Grok、GLM、DeepSeek、Kimi、Qwen、Ollama等任意模型，不用被绑死在一家。TypeScript，1.85万星（今日+54）。你手里有DeepSeek低价模型和Ollama本地模型，用它接到命令行agent里最灵活。
- **星级**：★★★★★
- **语言**：TypeScript
- **Star**：1.85万（今日+54）
- **部署建议**：旧笔记本上 `npm install -g @bitkyc08/opencodex`，配好你常用的模型key/Ollama地址。第一步：全局安装后看README的provider配置段，先接DeepSeek跑通第一条命令。

## ⭐ 值得装（4星）

2、[avenoxai/avenoxbeyin](https://github.com/avenoxai/avenoxbeyin)：一条命令搭出的AI第二大脑，跨会话长期记忆。
开源的Obsidian + Claude Code方案，聊天记录和笔记持久化保存，换会话不丢上下文，数据存在自己的Markdown仓库里。Python，462星（今日+51）。正好对口你关心的"AI要有长期记忆、笔记自己掌握"。
- **星级**：★★★★
- **语言**：Python
- **Star**：462（今日+51）
- **部署建议**：旧笔记本跑安装脚本，指定一个本地Obsidian笔记目录当记忆库。第一步：clone仓库后执行 `python3 scripts/install_v3.py --vault 你的笔记目录`。

3、[thesysdev/openui](https://github.com/thesysdev/openui)：生成式UI的开放标准。
让AI直接产出界面结构、前端用组件渲染，配套React等库和CLI脚手架，和昨天的a2ui是同方向的开放方案。TypeScript，1.52万星（今日+35）。你做机器人/HUD网页界面时，可以参考它怎么把AI输出变成可用界面。
- **星级**：★★★★
- **语言**：TypeScript
- **Star**：1.52万（今日+35）
- **部署建议**：先在线看示例，旧笔记本 `npx @openuidev/cli@latest create` 起一个演示项目。第一步：跑CLI生成脚手架，读懂它的JSON界面结构。

4、[netbirdio/netbird](https://github.com/netbirdio/netbird)：基于WireGuard的家庭组网Mesh VPN。
免配置点对点加密组网，自动发现机器、不用开端口和写防火墙规则，带后台管理Web UI和访问控制，支持Linux/macOS等。Go，今日+49。你把NAS、旧笔记本、旧手机、玩客云拉进同一个私有网络，在外网也能安全回连家里设备。
- **星级**：★★★★
- **语言**：Go
- **Star**：今日+49（总量以仓库页为准）
- **部署建议**：NAS或旧笔记本上自托管管理端，每台设备装NetBird客户端加入网络。第一步：看官网安装文档，先在一台Linux设备上装服务端。

## 👀 看兴趣（3星）

5、[Tencent/LoopForge](https://github.com/Tencent/LoopForge)：自托管的编码agent交付工作流平台。
在聊天里跟主Bot提需求，它开Docker沙箱、拉仓库、分派给项目角色、最后提PR；跑顺的流程能存成SOP（标准工作流），下次按同样方式交付，内置评审和人工审批闸口。Go，688星（今日+174）。适合想规范管理agent干活流程的人。
- **星级**：★★★ 🐎 黑马
- **语言**：Go
- **Star**：688（今日+174）
- **部署建议**：NAS Docker自托管试用，搭配你现有的编码agent。第一步：看README的Docker自托管段，起服务后在Web聊天里提第一条需求。

6、[crowdsecurity/crowdsec](https://github.com/crowdsecurity/crowdsec)：开源的入侵检测/WAF/爬虫防护。
社区共享恶意IP黑名单，能在Linux、Windows、Docker、K8s上跑，自动识别并封掉扫描、爆破、机器人流量。Go，1.56万星（今日+25）。你NAS对外暴露服务时，可以拿来挡一下恶意访问。
- **星级**：★★★
- **语言**：Go
- **Star**：1.56万（今日+25）
- **部署建议**：NAS Docker装一个采集器，接你暴露的服务日志。第一步：按官网文档在Docker里启动CrowdSec，先看默认告警。

7、[mvanhorn/last30days-skill](https://github.com/mvanhorn/last30days-skill)：跨平台调研一个话题并出总结的agent技能。
agent技能包，自动去Reddit、X、YouTube、HN、Polymarket和全网搜资料，再综合成一份有依据的总结。Python，6.76万星（今日+111）。想让兔子帮你调研某个方向（比如本地AI、语音助手方案）时可参考这类技能写法。
- **星级**：★★★
- **语言**：Python
- **Star**：6.76万（今日+111）
- **部署建议**：不单独部署，把它当技能接到你的agent里。第一步：clone后读README，看技能是怎么定义调研来源和总结格式的。

8、[shanliuling/dsh-image-gen](https://github.com/shanliuling/dsh-image-gen)：对话内生成、编辑、对比图片的AI画图工作室。
内置500+提示词、图库和多模型工作流，支持ComfyUI，在聊天里直接出图、改图、对比方案。TypeScript，1.49k星（今日+95）。想给机器人界面、海报做配图可以玩。
- **星级**：★★★
- **语言**：TypeScript
- **Star**：1.49k（今日+95）
- **部署建议**：旧笔记本按README装DSH插件 `pnpm dsh plugin --profile web add dsh-image-gen@latest`。第一步：装好后先跑一张默认提示词看效果。

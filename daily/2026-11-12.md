# GitHub热门Top10 · 2026-11-12

> 每天抓取GitHub热门项目，大白话解读，告诉你值不值得折腾。

## 🔥 强烈推荐（5星）

1、[activepieces/activepieces](https://github.com/activepieces/activepieces)：自托管的AI Agent + MCP + 工作流自动化平台。
开源版攒了约400个MCP服务器和集成件，像免费的Zapier：把"收到消息→查数据库→调AI→推送到微信/飞书"这类流程拖成自动化，AI agent也能在上面跑。TypeScript，2.55万星，今天还在活跃更新。
- **星级**：★★★★★
- **语言**：TypeScript
- **Star**：2.55万
- **部署建议**：你飞牛NAS的Docker直接起一套，给兔子agent接工作流和MCP工具。第一步：clone仓库看README的Docker Compose部署段，起服务后浏览器登录。

## ⭐ 值得装（4星）

2、[isair/jarvis](https://github.com/isair/jarvis)：跑在本地桌面的私有AI助手，带语音对话和个人记忆。
Python写的，语音+文字聊天、个人记忆、听写、MCP工具都有，接你自己的模型（Ollama/DeepSeek都行），不上云。2.2k星，和你正在做的语音助手项目方向几乎一致，可直接抄架构。
- **星级**：★★★★
- **语言**：Python
- **Star**：2.2k
- **部署建议**：旧笔记本上跑，Python 3.11+，`git clone` 后按README装依赖，配本地模型地址。第一步：clone仓库看 Quick Install 段，先把麦克风识别调通。

3、[EverMind-AI/EverOS](https://github.com/EverMind-AI/EverOS)：给所有AI agent共用的一层可移植记忆。
本地优先、Markdown原生、数据归你自己，agent之间能共享并自演化记忆。Python，1.39万星。正好解决你关心的"AI要有长期记忆、换个模型不丢上下文"。
- **星级**：★★★★
- **语言**：Python
- **Star**：1.39万
- **部署建议**：NAS或旧笔记本上 `pip install everos`，接在兔子agent前面当记忆层。第一步：装好后看 QUICKSTART.md 接你的agent。

4、[Mintplex-Labs/anything-llm](https://github.com/Mintplex-Labs/anything-llm)：本地优先的私有知识库和agent平台。
把你的文档、PDF、聊天记录喂进去做RAG问答，数据全在自己机器上，可接Ollama本地模型。JavaScript，6.82万星，成熟稳定。
- **星级**：★★★★
- **语言**：JavaScript
- **Star**：6.82万
- **部署建议**：飞牛NAS Docker部署，挂一个存储目录放知识库。第一步：拉Docker镜像，配Ollama地址，先传几份文档试问答。

5、[NanmiCoder/cc-haha](https://github.com/NanmiCoder/cc-haha)：本地优先的跨平台AI Agent桌面工作台。
多Agent协作、Git分支、代码Diff、技能市场、多模型、Computer Use，还带桌面宠物，支持微信/飞书/钉钉接入。TypeScript，1.54万星，思路和你的兔子+HUD+桌面机器人很贴。
- **星级**：★★★★ 🐎 黑马
- **语言**：TypeScript
- **Star**：1.54万
- **部署建议**：旧笔记本下Release桌面端，接你自己的模型服务试用。第一步：下载对应系统安装包，首次在设置里填模型API地址。

## 👀 看兴趣（3星）

6、[Evil0ctal/Douyin_TikTok_Download_API](https://github.com/Evil0ctal/Douyin_TikTok_Download_API)：自托管的抖音/TikTok/B站无水印下载API。
Python写的，2.14万星，支持AI agent通过MCP调用，还能离线语音转文字，Docker一键部署。想批量存视频、做素材库可以用。
- **星级**：★★★
- **语言**：Python
- **Star**：2.14万
- **部署建议**：NAS Docker起一个，给agent提供下载/解析接口。第一步：clone后按README用Docker启动，访问本地API端口。

7、[QwenLM/qwen-code](https://github.com/QwenLM/qwen-code)：通义千问开源的终端AI编码agent。
TypeScript，2.95万星（今日+151），住在命令行里帮你写代码、改文件、跑命令。你不写正式代码也能拿来让它帮你改脚本、读报错。
- **星级**：★★★
- **语言**：TypeScript
- **Star**：2.95万（今日+151）
- **部署建议**：旧笔记本终端装，可接兼容API。第一步：按README装CLI，配好模型key跑第一条命令。

8、[codexu/note-gen](https://github.com/codexu/note-gen)：本地优先的Markdown记录App，先随手记、再由AI整理。
TypeScript，1.30万星，零散记录丢进去，AI帮你归类成清晰笔记，数据本地存。适合攒你的折腾笔记和设备备忘。
- **星级**：★★★
- **语言**：TypeScript
- **Star**：1.30万
- **部署建议**：旧笔记本或旧手机装客户端，Markdown文件夹可同步到NAS。第一步：clone看README本地运行方式。

9、[AbhishekBarali/SpeakoFlow](https://github.com/AbhishekBarali/SpeakoFlow)：免费开源的离线语音听写工具。
Rust写的，Windows/macOS/Linux都支持，Wispr Flow的开源替代，在任何软件里用语音转文字。399星，刚起步，适合想做本地语音输入的你参考。
- **星级**：★★★
- **语言**：Rust
- **Star**：399
- **部署建议**：旧笔记本下载Release试用，需要本地STT模型。第一步：看README装依赖、选模型后在输入框试听写。

## 📌 关注（2星）

10、[nvm-sh/nvm](https://github.com/nvm-sh/nvm)：Node.js 版本管理器。
Shell脚本，9.59万星（今日+79），在一台机器上切换不同Node版本。你装上面那些TS工具（activepieces、qwen-code等）时大概率会用到，本身不是应用，了解即可。
- **星级**：★★
- **语言**：Shell
- **Star**：9.59万（今日+79）
- **部署建议**：不单独"部署"，旧笔记本开发环境装一个备用。第一步：按README脚本安装，`nvm install --lts` 装长期支持版Node。

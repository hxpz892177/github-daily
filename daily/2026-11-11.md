# GitHub热门Top10 · 2026-11-11

> 每天抓取GitHub热门项目，大白话解读，告诉你值不值得折腾。

## 🔥 强烈推荐（5星）

1、[vercel-labs/agent-desktop](https://github.com/vercel-labs/agent-desktop)：让AI agent直接看见并操作你电脑桌面软件。
Vercel Labs出的Computer Use工具，不靠截图认像素，而是读取桌面App的无障碍树（Accessibility Tree）返回JSON，每个按钮都有编号，agent点编号、打字、再读界面核对结果，循环操作。自带CLI和C库，macOS/Windows/Linux都支持，里面不含模型，接你自己的兔子/Ollama就行。
- **星级**：★★★★★ 🐎 黑马
- **语言**：Rust
- **Star**：2.17万（本周+9,502）
- **部署建议**：你想让兔子agent自动操作电脑网页/软件，这就是底座。装在旧笔记本上，`npm install -g agent-desktop`，第一步跑 `agent-desktop status` 看系统权限是否就绪。

## ⭐ 值得装（4星）

2、[opensandbox-group/OpenSandbox](https://github.com/opensandbox-group/OpenSandbox)：给AI agent跑代码的安全沙箱运行时。
agent让它写脚本、装依赖、跑命令时，把不可信代码关进隔离沙箱里执行，不碰你主机文件。Go写的，1.7万星，安全、快、可扩展，适合自托管agent平台做执行隔离。
- **星级**：★★★★
- **语言**：Go
- **Star**：1.72万（今日+323）
- **部署建议**：飞牛NAS的Docker里起一个沙箱服务，给你的兔子agent当"执行工位"，防止乱删文件。第一步：clone仓库看README的Docker部署段。

3、[shadcn/improve](https://github.com/shadcn/improve)：让强模型审代码库、写好计划，再交给便宜模型干活。
一个Agent Skill：先用你最强的模型通读整个代码库、判断哪些值得改、写成一份份独立的Markdown实施计划；它自己不写代码，计划就是产物，再交给便宜模型去实现、测试、上线。省模型钱的思路很实用。
- **星级**：★★★★
- **语言**：TypeScript
- **Star**：1.04万
- **部署建议**：接在你现有的编码agent上，`npx skills add shadcn/improve` 即可，计划存成Markdown谁都能接手。第一步：在agent目录里跑这条安装命令。

## 👀 看兴趣（3星）

多源行情、实时新闻、决策看板、自动推送一条龙，支持零成本定时跑。Python写的，6.9万星，今天+960。你关注增收和理财，可以拿来盯行情，但注意：分析只是参考，别拿它当买卖依据。
- **星级**：★★★
- **语言**：Python
- **Star**：6.97万（今日+960）
- **部署建议**：旧笔记本或NAS上用Python定时跑，接免费/低价大模型API。第一步：clone下来看README的定时任务和推送配置。

5、[shy3130/tick-stock-panel](https://github.com/shy3130/tick-stock-panel)：自托管、零运维的A股量化工作台。

- **星级**：★★★
- **语言**：Python
- **Star**：7.6k（今日+108）
- **部署建议**：NAS Docker或旧笔记本自托管，浏览器打开看盘。第一步：clone后按README配数据源。

6、[google/skills](https://github.com/google/skills)：Google官方出的产品Agent Skills合集。
把Google Cloud、Google系产品的用法做成标准Agent Skill，`npx skills add google/skills` 按需装。2.4万星，Python为主。你以后用到Google系工具时可以直接给agent装上。
- **星级**：★★★
- **语言**：Python
- **Star**：2.39万
- **部署建议**：不单独部署，作为技能包装进你的agent。第一步：`npx skills add google/skills` 选需要的技能。

7、[GoogleChrome/modern-web-guidance-src](https://github.com/GoogleChrome/modern-web-guidance-src)：把现代Web最佳实践塞进编码agent的技能包。
Chrome、Edge、火狐、MDN团队联合维护，教agent别用老掉牙写法，直接用现代Web平台能力。TypeScript源码仓库，1.4k星。你做HUD/兔子网页界面时可以让agent参考。
- **星级**：★★★
- **语言**：TypeScript

- **部署建议**：不部署，当agent技能装。第一步：`npx modern-web-guidance@latest install`。

8、[Donchitos/Claude-Code-Game-Studios](https://github.com/Donchitos/Claude-Code-Game-Studios)：描述一句话，AI给你做个能玩的浏览器游戏。
你说"做个黄昏才钓得到稀有鱼的钓鱼游戏"，Claude Code先问几个问题、写一页简报，再生成可在浏览器里玩的游戏，然后一步步改大。3.8万星，正好对上你怀旧游戏的兴趣。

9、[krahets/hello-algo](https://github.com/krahets/hello-algo)：动画图解、一键运行的算法教程，中文友好。

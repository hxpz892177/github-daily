# GitHub热门Top10 · 2026-10-02

> 每天抓取 GitHub 热门项目，大白话解读，告诉你值不值得折腾。

**今日结论**：核心判断：今天最大亮点是黑马 HowToLiveBetter（循证生活指南，直接解决你最近关心的省钱、法律、育儿问题）；另外 pi 和 superpowers 两个本地AI工具包值得装。

## 🔥 强烈推荐（5星）

1、[HowToLiveBetter](https://github.com/HowToLiveBetter/HowToLiveBetter) 🐎 黑马：省钱/法律/育儿/社保循证指南，直接解决你最近的烦恼，网页即看

一个按"性价比"排序的循证生活指南，覆盖长寿防病、急救、省钱理财、法律红线、失业与工伤、医保社保、恋爱婚育、怀孕育儿、创业合规、出国与技能。每条都写明成本、收益、证据等级和原始出处，只引期刊论文和官方文件。

- **星级**：★★★★★
- **语言**：HTML
- **Star**：1.78万
- **部署建议**：为什么5星：它是 9月7日 才上线的黑马，不到一个月 1.78万星。更重要的是——它几乎是你最近所有烦恼的"答案书"：省钱理财（你的房贷/装修贷/信用卡压力）、法律红线（你问过的婚前房产加名、雷达合法性）、医保社保（你的碎片化社保）、怀孕育儿（儿子幼升小）。不需要安装部署，手机浏览器打开网页就能看。

## ⭐ 值得装（4星）

2、pi：AI智能体工具包，统一Ollama和各家API，接阿库/OpenClaw

一个 AI 智能体工具包：统一各种大模型的 API、提供智能体运行循环、终端界面和编码助手。

- **星级**：★★★★
- **语言**：TS
- **Star**：11.1万
- **部署建议**：你有 Ollama 本地模型 + Docker 环境，它能把 Ollama 和各家 API 统一成一个入口，接阿库/OpenClaw 用。适合你"本地AI"的玩法，但主要是终端操作，对你来说偏折腾，所以给4星而不是5星。

3、superpowers：AI技能框架，参考它把阿库的记忆目录建得更规范

一套给 AI 加"技能"（skills）的框架和开发方法论，让 AI 具备可复用的工作能力。

- **星级**：★★★★
- **语言**：Shell
- **Star**：29.4万
- **部署建议**：你昨天刚在给阿库配"分类记忆"技能，这个项目就是讲怎么系统化地给 AI 配技能的。参考它的技能组织思路，能帮你把阿库的"图书目录"建得更规范。

## 👀 看兴趣（3星）

- **星级**：★★★
- **语言**：TS
- **Star**：3.1k
- **部署建议**：贴你的"视频下载投屏"话题，但它是终端工具（需要敲命令），且下载版权内容有灰色地带。想省心不如用现成下载器。
